Why KS Panel

Everything a game host needs.
Nothing it doesn't.

One Go binary for the panel, one tiny agent per node. No per-server license fees, no closed core — just a fast control plane that scales from a single VPS to a full fleet.

Core
🚀

One-click lifecycle

Install, start, stop, restart, reinstall and kill any server. Idempotent actions with staleness guards so Stop always targets the right process.

🖥️

Live console

Real-time WebSocket terminal with ANSI colors, title/CWD tracking, attach-to-main-process and fit + web-links addons.

📁

File manager

Browse, edit, upload (even from URL with SSRF hardening), chmod and stream files — with syntax highlighting and SFTP access.

⏱️

Automation

Cron jobs, multi-step plans (run on success / failure / always), backups, restarts and commands — with run history.

🔐

Secrets vault

AES-256-GCM encrypted env & secrets per server. Masked by default, every reveal is audit-logged.

📸

Snapshots & backups

Driver snapshots plus resumable file-level tars (Content-Range + Range downloads), retention policies and S3 push/pull.

Architecture

Panel + Edge. Scales horizontally.

The Panel is the central UI + API. The Edge agent runs on every host and executes what the panel asks. Add unlimited nodes — direct, reverse-tunnel, or local modes.

◈ Panel central

Single Go binary. Serves the React UI, API, scheduler, auth, billing-adjacent primitives (tickets, audit, API keys) and talks to every Edge node.

  • React 18 + Vite UI, Tailwind tokens
  • SQLite / Postgres / MySQL + live engine switch
  • 121-key RBAC, OAuth ×5, TOTP + recovery codes

⬡ Edge per host

Lightweight agent with zero DB. Owns containers/VMs, files, exec, telemetry and heartbeats. No UI, no state to lose.

  • Docker · KVM/QEMU · LXD · Multipass
  • Heartbeat + probe + reverse-tunnel WSS
  • Self-updates with verified downloads

FAQ

Questions, answered

Is KS Panel really free? +

Yes. MIT licensed, self-hosted, unlimited instances and nodes. No per-server fees, no feature gates — the same binary runs a hobby VPS and a provider fleet.

What games are supported? +

Minecraft (Java & Bedrock), Valve titles (CS2, TF2, Garry's Mod), Rust, Palworld, Valheim, Terraria, Factorio, ARK — plus any custom app via 40+-field blueprint templates.

How is this different from Pterodactyl / Pelican? +

Same spirit, wider scope: 4 virtualization drivers (not just Docker), deeper RBAC (121 keys), built-in tickets/notifications, AI chat, theming marketplace, instance pages, self-update with fleet rollout — see docs/vs.md for the full matrix.

How do nodes work? +

Install the tiny ksedge agent on each host (direct, reverse-tunnel or local mode). The panel pairs over token, probes health, collects heartbeats and dispatches exec/files/lifecycle over HTTP or WSS.

Which databases are supported? +

SQLite for single-host, PostgreSQL or MySQL for fleets — transparent, with a live engine switch (datamove) and scheduled compressed backups to disk or S3.
