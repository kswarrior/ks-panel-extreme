Features

One panel. Every workflow.

Mapped 1:1 from the actual codebase — panel backend (Go API), panel frontend (React), edge agents (Go), instance pages (YAML) and the theme marketplace. Nothing on this page is mock-marketing.

🖥️ Instance management

Fleet-grade server ops

🚀

Lifecycle

One-click install / start / stop / restart / reinstall / kill / suspend. Staleness-guarded actions, cooldowns and max-runtime auto-stop.

💻

Console

WebSocket terminal, ANSI colors, reconnect states, attach to the main process, live install-output streaming.

📁

Files

List / read / write / mkdir / rename / chmod / stat, URL upload, inline editor + SFTP + jailed paths.

📊

Metrics

CPU / RAM / disk / load sparklines polled live from Edge, per-process list with kill, ports & allocations view.

⏱️

Automation

Cron schedules, typed shell/power/action jobs, multi-step plans, manual run + full run logs.

🔐

Secrets

AES-256-GCM vault per instance, masked list, audited reveal, secret refs inside automation.

⬡ Nodes & edge

Unlimited hosts, four drivers

4 drivers
🐳

Docker · KVM · LXD · Multipass

Run featherweight containers or fully isolated VMs. Per-node driver flags, overcommit %, alloc caps and install dirs.

💓

Health & heartbeats

Per-minute heartbeat buckets, 24h uptime sparklines, probe reachability, stale/partial vs fully-up states.

🔀

Connection modes

Direct HTTP, reverse-tunnel WSS (for NAT boxes), local-port and local-WSS. Token rotation + purge built in.

🔄

Fleet updates

Verified downloads (SHA256 + cosign), rolling node update-all, scheduled maintenance windows, background auto-checks.

📸

Snapshots

Driver snapshots + scheduled snapshot policies with keep-last-N / max-age pruning.

💾

Backups

Resumable file tars (Content-Range upload, Range download), gzip/zstd, S3 SigV4 push/pull, DB + file schedules.

🛡️ Access & security

Provider-grade trust model

121 keys
🧾

RBAC

17 area groups, umbrella + granular + Own/All scopes, power sub-verbs, theme & AI sub-caps, per-field profile enforcement.

🔑

Auth hardening

bcrypt + TOTP + recovery codes, 5-provider OAuth, lockout (5/15m), rate limits, suspend, device limits, hardened sessions.

📜

Audit everywhere

Global activity log + per-instance timeline. Every mutation, reveal and admin action recorded with IP + agent.

🛎️

API keys

Self-serve + admin keys, SHA256 stored, expiry, rate limits, scope edits, request ledger.

🧱

WAF posture

IP allow/deny, suspicious-path blocks, DDoS auto-stop with cooldown, SSRF-hardened URL installs, SVG sanitizer.

🗄️

Multi-DB

SQLite / Postgres / MySQL transparent via migrations (077 IDs ×3 dialects), live datamove switch, inspector UI.

🧩 Extensibility

Make it yours

🎨

Themes

Studio with 15 tabs (accent, background, cards, sidebar, loading…), per-area scopes, custom CSS, marketplace + history/rollback.

📄

Instance pages

YAML-authored custom tabs (files, terminal, env, ports, automation, dashboards…), blocks/React/HTML/Markdown, KSPageSDK.

🔌

Mods & apps

Goja-sandboxed mod engine with event bus + slots, .kspm packages; app catalog with file staging, env + runs.

🏗️

Stacks

Full-stack apps: catalog + proxy + remote pairing + serve ports. Host dashboards next to game servers.

🎫

Tickets

Numbered queue, threaded + internal comments, attachments, per-category SLA, escalation, email fan-out.

🤖

AI chat

Scoped assistant (QA / tools / writes / threads) with per-user isolation — help without handing over keys.
