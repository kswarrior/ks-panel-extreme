Get started

From zero to game server in 3 steps

No account, no license key, no sales call. Just a container (or two binaries) and a browser.

1️⃣

Install the panel

One Docker command or a single Go binary. Open :8080, create your admin user, done.

2️⃣

Connect a node

Run ksedge on each game host, paste the token. Works behind NAT via reverse-tunnel.

3️⃣

Deploy a server

Pick a template (Paper, CS2, Rust…), pick a node, hit Deploy. Console, files and ports are ready instantly.

Step 1 — install

Pick your install method

🖥️ Linux hostUbuntu 22.04+, Debian 12+ recommended
🐳 DockerRequired for container servers
🌐 Port 8080Panel UI + API (configurable)
💾 1GB freePlus space for game servers
terminal
# 1 — run the panel
docker run -d \
  --name kspanel \
  --restart unless-stopped \
  -p 8080:8080 \
  -v kspanel-data:/data \
  ghcr.io/your-org/kspanel:latest

# 2 — open the UI and create your admin user
http://YOUR-SERVER-IP:8080
# panel (controller)
chmod +x release/kspanel
./release/kspanel --port 8080

# edge agent (on EACH game host)
chmod +x release/ksedge
./release/ksedge
git clone https://github.com/your-org/ks-panel.git
cd ks-panel
bash rebuild.sh
./release/kspanel
Step 2 — add a node

Connect your first game host

Same machine (homelab)

Panel → Nodes → Setup local downloads and launches ksedge for you. Perfect for testing.

  • No firewall work
  • Docker driver ready
  • Upgrade to remote later

Remote host (production)

Create the node in the UI, copy its token, then on the game host:

./ksedge --panel https://panel.example.com \
  --token PASTE_TOKEN_HERE
  • Behind NAT? use reverse-tunnel mode
  • Rotate tokens anytime
  • Heartbeat proves it's alive
